# 连线系统设计

> 连线子系统（`src/flow/edges/`）的设计决策与不变式。实现细节按代码注释；验收结论见 [../变更详情/2026-11-03-连线重构自检报告.md](../变更详情/2026-11-03-连线重构自检报告.md)。最后更新：2026-11-21

## 设计目标

连线是交互流程图的核心语义（哪个按钮 → 跳到哪个界面），必须满足：

1. **线不穿卡** —— 由构造保证（不变式过滤），不是逐案修补；
2. **点=线=箭头同色**（ComfyUI 的核心可读性特征），颜色由热点语义单一来源决定；
3. **任何缩放级别手感一致** —— 命中区、线宽、箭头、光带全部按 1/zoom 反向补偿；
4. **画布静着好看、动着流畅** —— 拖拽路径上是纯几何计算，动画只走合成线程。

## 通用候选路由 v2（2026-11-03 重构）

`edges/edgeRouting.ts` 的 `computeEdgeEndpoints`：

- **候选生成** `generateCandidates`：直连（圆点朝外 + 两个沿边方向）、沿边绕角、对面贴合（回边）、四面绕行、净空线保底（直角肘形，构造上不穿卡，保证密集布局下总有解）；
- **不变式过滤**：候选路线的 64 点采样侵入任一卡片 >2px 即淘汰（含源/目标卡自身）；全部无效时按「侵入最浅」回退；
- **打分**：路径长度 + 每段惩罚（`LEG_PENALTY=12`）+ 脱离语义圆点惩罚（`DETACHED_PENALTY=400`，保线锚在按钮上）；
- 贝塞尔曲线化：控制柄按端口方向计算（正向 `clamp(dist*0.32, 40, 120)`），追赶构型目标柄后收防 180° 折返；绕行候选的直角肘形拐角加 12px Q 圆角（`roundedStraightTail`，半径钳制相邻段一半）；
- **无缓存**：候选生成是纯几何计算，测试图规模（≤200 卡）无感知延迟；旧 LRU 路由缓存层已删除。

已知的可接受回退：bench 密集网格（卡距 40–80px）随机跨列边在全部候选无效时最深侵入 ~15px。

## 边组件管线（`edges/edges.tsx`）

`FlowEdge` = 路由几何 → 箭头 marker（`arrowScale = min(2.2, 1/zoom)`）→ 主线 → 起点圆点 → 活性光晕 → 命中区（恒定 10 屏幕像素）→ 选中标签（`EdgeLabelRenderer`，zoom<0.18 隐藏）→ 流动光带。

- **共享派生状态**（`edgeStoreSelectors.ts`）：zoom / lane 分组 / 节点几何 / 可视区按 zustand state 对象 WeakMap 记忆，一帧全图只派生一次（O(E×N)→O(N+E log E)）。
- **选中活性**（`selectionSignal.ts`）：App 的 `onSelectionChange` 发布选中 id 集合（内容不变免打扰），各边 O(1) 查询；相连边垫 10px 同色光晕，其余整组淡到 0.22。
- **标签**：沿全路径采样取 70%~85% 区间，lane 偏移让同目标多线错开；默认只显示方向箭头，选中才浮现标签。
- **拖线反馈**（`BezierConnectionLine`）：拖线色继承起点热点语义色；卡面 O(N) 命中测试（派生几何缓存，排除起点卡）——悬停任意卡面即转实线+光晕，与 `onConnectEnd` 落卡兜底所见即所得。RF v12 的 `connectionindicator` 只挂 handle 级，拖线态信号由 `useConnection` 驱动的 `data-drag` 属性承载（见 [../质量与验收/验收方法论.md](../质量与验收/验收方法论.md)）。

## 流动光带（`edges/FlowStreaks.tsx` + `pathSample.ts`）

- 选中/悬停/与选中相连的边挂彗尾光点（16 点、头 5px 尾 2px、间距 1.7px 互相压叠），沿线按数据方向走；长线（>200px）最多两道。
- 关键帧由 `pathSample.ts` 纯 JS 解析 SVG path 弧长采样（M/L/H/V/Q/C/Z）——不走 `getTotalLength`，拖卡片零主线程重解析；一条线只解析一次 `KeyframeEffect`，各点克隆负延迟。
- 只动 transform/opacity（合成线程）；路径连续变 → 整组淡出暂停，停稳 140ms 重铺；尺寸按 1/zoom 反补偿（clamp 0.55–1.8）；`prefers-reduced-motion` 全关。
- 替代了原「每边常驻 SMIL 流动小点」——静画布归静，动线才流。

## 语义配色（`edges/edgeColors.ts`）

- yes=绿 / no=红 / 通用出口=中性石板；提交/支付类→靛蓝、返回类→琥珀、列表/导航→青、收藏→品红、成员/分享→水鸭、辅助→紫；
- 未识别 handle 按 id 稳定哈希散列到 8 色板，同 id 恒色；
- 颜色单一来源注入到节点 Handle、连线、箭头、拖线反馈与选中环。

## 已明确不做

- 手动控制点（连线重路由）：需求文档可选项，自动路由已覆盖主要场景（见 [../任务与待办.md](../任务与待办.md)）；
- 节点自连接：`isValidConnection` 拦截 + 提示，追赶构型对自连无意义，维持禁止。
